Database Setup (One-Click SQL Schema)

Run this once in your Supabase SQL Editor to create tables, indexes, and storage buckets.

-- Schema file: supabase-schema.sql

CREATE TABLE public.events (...);

CREATE TABLE public.registrations (...);

CREATE POLICY "Public can insert registrations" ON public.registrations;

INSERT INTO storage.buckets (id, name, public) VALUES ('receipts', 'receipts', true);

1. Open Supabase Dashboard and choose your project.

2. Click SQL Editor on the left side.

3. Paste the copied SQL and click RUN.
